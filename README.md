# Mohamed Wasim — Contact

A simple, responsive digital contact card with a contact form.

## About

Personal contact page for Mohamed Wasim, AI Coding Engineer based in Dubai, UAE.
Includes quick links for phone, email, WhatsApp, Telegram, LinkedIn, and GitHub,
plus a message form powered by EmailJS.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- EmailJS (contact form)

## Deployment

This is a static site. Deployable files are in the root directory.

- Install command: none
- Build command: none
- Publish folder: `/`

## Local Preview

Open `index.html` in your browser, or serve the folder:

```bash
npx serve .
```
