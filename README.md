# Mohamed Wasim — Contact

A simple, responsive digital contact card with a contact form.

## About

Personal contact page for Mohamed Wasim, AI Coding Engineer based in Dubai, UAE.
Includes quick links for phone, email, WhatsApp, Telegram, LinkedIn, and GitHub,
plus a message form powered by EmailJS.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- EmailJS (contact form)

## Live Site

Deployed via [cleverotter.eu](https://cleverotter.eu).

## Project Structure

```
.
└── dist/
    ├── index.html
    ├── styles.css
    ├── script.js
    └── Image.jpeg
```

## Deployment

This is a static site. The deployable files live in the `dist/` folder.

- Install command: none
- Build command: none
- Publish folder: `dist`

## Local Preview

Open `dist/index.html` in your browser, or serve the folder:

```bash
npx serve dist
```
